El Modelo Kirkpatrick Aplicado

Nuestra arquitectura integra métodos de recolección de datos en cuatro capas fundamentales, permitiendo medir desde la percepción inicial hasta el retorno de inversión (ROI).

Nivel 4: Resultados
Nivel 3: Comportamiento
Nivel 2: Aprendizaje
Nivel 1: Reacción

Nivel 1: Reacción (Satisfacción)

Formularios reactivos (Nuxt) guardados en `satisfaction_surveys`.

↣ Métrica: Net Promoter Score (NPS)

Nivel 2: Aprendizaje (Conocimiento)

Evaluaciones Pre/Post. Supabase maneja intentos y validación.

↣ Métrica: Delta de conocimiento

Nivel 3: Comportamiento (Transferencia)

Edge Functions envían correos 30-60-90 días pos-curso a jefes.

↣ Métrica: % de aplicación en el puesto

Nivel 4: Resultados (Impacto)

Cruce de datos de capacitación con KPIs del negocio mensual.

↣ Métrica: Retorno de Inversión (ROI)

Proyección de Retención del Conocimiento

Un LMS tradicional pierde efectividad rápidamente. Al implementar evaluaciones continuas y seguimiento de comportamiento a los 30, 60 y 90 días (Nivel 3 de Kirkpatrick), la retención del conocimiento y su aplicación mejoran drásticamente.

Modelo Relacional de Datos

Para garantizar alta eficiencia y tiempos de respuesta óptimos a nivel nacional, la base de datos PostgreSQL en Supabase se estructura en tablas clave. Esta proyección muestra el volumen estimado de interacciones por usuario durante el primer año.

Fases de Implementación

Fase 1: MVP (Mínimo Viable)

Gestión de 200 usuarios iniciales, visualización de videos optimizados y ejecución de cuestionarios básicos para validar los Niveles 1 y 2.

Fase 2: Gamificación y Cobertura

Implementación de certificados automatizados, ranking de progreso y optimización de assets estáticos (Nuxt Image) para conexiones lentas.

Fase 3: Transferencia (Nivel 3)

Creación del panel de seguimiento para supervisores y configuración de Supabase Edge Functions para disparar encuestas de desempeño en el puesto.

Fase 4: Analítica Avanzada (Nivel 4)

Desarrollo del Dashboard ejecutivo integrando bases de datos externas de la compañía para calcular el impacto organizacional (ROI/ROE) directo.
